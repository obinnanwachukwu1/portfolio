tracecode harness runs interactive workspaces and isolated evaluations in the browser. the harness handles compiling and executing code across 6 languages completely in the browser. tracekernel owns the files, processes, terminals, and language runtimes. tracecode judge takes a versioned problem or project definition and returns the evidence, score, and verdict.
